## Current Work

Solo developer building internal tools for construction/environment workflows.

- **Hourly Rainfall Calculator**: structured rainfall calculation and review workflow
- **Sunlight Analysis**: GIS/CAD/DXF-driven analysis workflow support
- **Slope Calculator**: slope and engineering review calculation support

The goal is not just to make small utilities. The goal is to standardize work, reduce repeated data entry, cut manual operations, lower human error, and internalize workflows that used to depend on paid external software.

## AI-Native Development Workflow

I use AI as part of the engineering system, not as a side assistant.

- System design with Claude and Codex
- Code generation, refactoring, and implementation support
- Test planning and verification loops
- Documentation and technical writing
- Code review and risk checking
- Multi-agent orchestration for planning, building, reviewing, and validating
- Multi-AI orchestration across different models and roles

AI is the multiplier. Product thinking is the filter. Domain work is the material.
